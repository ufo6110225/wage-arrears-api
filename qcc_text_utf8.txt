7.1接口请求方式
参数名 类型 传递方式 说明
Token String http header 头 验证加密值 见加密约定
Timespan String http header 头 精确到秒的 Unix时间戳
SecretKey String 不传递 密钥，请妥善保管好
加密约定：
Token：key + Timespan +  SecretKey 组成的 32位md5加密的大写字符串
备注：SecretKey、Key 都可以在企查查开放平台官网获取

当前所有的接口使用说明将放到企查查开放平台网站(openapi.qcc.com)，
